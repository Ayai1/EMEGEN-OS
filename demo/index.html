Time-aware conversational memory

Facts change. Memory needs a history.

Persistent agents can keep an old value after a person updates it, or accept a conflicting claim from a document. EngramOS records where a fact came from, when it applied, and whether an incoming turn was quarantined.

This page demonstrates neutral personal facts such as a home city and editor preference. A local SQLite database holds each demo session.

What EngramOS does

A gated, temporal memory path

Facts are stored in named slots with provenance and bitemporal validity. A later fact can supersede an earlier one while preserving the old interval. Queries can ask for a current value, a value as of a date, or the ordered history.

Ingestion

The deterministic gate evaluates bridge, policy, and source signals before extraction. In the default mode, an untrusted turn with one fired signal is stored but remains unverified. Two fired signals quarantine it.

Question answering

The classifier selects current, as-of, or history view. Retrieval returns eligible evidence, then the Reader returns an answer with citations or abstains. Hybrid retrieval is a comparison baseline in the saved evaluations.

    How to read this

    These small authored samples describe recorded prototype runs. They do not establish extraction quality, broad generalization, or real-world attack prevalence. V3 accuracy is displayed only when its result file is present.

    Scope, safety, and licenses

    A local demo with clear boundaries

    EngramOS stores and retrieves user-stated facts. It does not provide medical, mental-health, legal, or financial advice and does not make personality assessments.

    Demo-only: single-user local SQLite, no authentication, and no encryption at rest. The role and source labels are supplied by the caller.

    Project files: README.md · LICENSES.md

    Run it yourself

    Meta models only, with lexical FTS5 retrieval:

    .\.venv\Scripts\python.exe demo\server.py --mode live --embedding none

    Muse Glimmer plus optional non-Meta BGE-M3 retrieval embeddings:

    .\.venv\Scripts\python.exe demo\server.py --mode live --embedding bge

    Play a saved session without contacting a provider:

    .\.venv\Scripts\python.exe demo\server.py --mode replay --embedding none

    Save the scripted session and run checks:

    .\.venv\Scripts\python.exe demo\record_session.py
.\.venv\Scripts\python.exe scripts\preflight.py

    The demo interface and its standard-library server were built during the hackathon.
